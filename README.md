# Data-Analysis-of-VoltRelay-Energy-Operations-
Diagnosed a massive 40% rider churn rate within VoltRelay Energy's EV battery-swapping network. Analyzed 3.9M transactions using Python and Pandas to prove that Gen1 hardware failures during peak mealtime rushes were destroying gig-worker retention. Includes data-driven CapEx and budget reallocation strategies to stop the bleeding.
